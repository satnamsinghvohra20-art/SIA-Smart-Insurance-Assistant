        [Upload Bill PDF] ──▶ Intake Agent (Gemini 3.5 Multimodal OCR + Confidence)
                                │ (Writes structured fields to Firestore)
                                ▼
                            Decision Agent (Deterministic Rules Engine + Gemini Ambiguity)
                                │ (Computes co-pay, waiting periods, sub-limits, exclusions)
                                ▼
                            Execution Agent (IRDAI Claim Form PDF + Evidence Checklist)
                                │
                                ▼
                            [Human Approval Gate]
                                │
                                ▼
                            Pub/Sub Event ──▶ Cloud Run Worker (Async TPA Polling)
